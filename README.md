# DayBloc Resources & Time Blocking Guides

Welcome to the official public documentation for **DayBloc**, a visual time-blocking app designed to help you plan your day, protect your deep work, and build lasting habits without the need for an account or an internet connection.

This repository contains practical guides on time management, deep work, and how to use visual time blocking effectively.

## What is DayBloc?
DayBloc is a simple time-blocking app that turns your schedule into a color-coded visual timeline. Instead of an endless to-do list, you give every hour a home. It is built for people who value privacy, speed, and focus.

- **Website:** [https://daybloc.app](https://daybloc.app)
- **Download on Google Play:** [DayBloc on Google Play](https://play.google.com/store/apps/details?id=com.daybloc.app)
